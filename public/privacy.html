개인정보처리방침

4조 근무표 (https://kimhyunsik999.github.io/hskim-calendar/) · 시행일 2026년 11월 23일

4조 근무표(이하 "앱")는 교대 근무 일정을 확인하고 가족과 공유하기 위한 개인용 웹앱입니다. 앱은 별도의 회원 데이터베이스를 운영하지 않으며, 사용자의 일정 데이터는 사용자 본인의 Google 계정(Google Calendar)에 저장됩니다.

1. 처리하는 정보와 목적

정보목적저장 위치 · 기간
Google Calendar 일정·캘린더 목록 (Google 계정 연결 시)달력 표시, 근무 일정·근무 변경·메모의 생성·수정·삭제, 근무 알림 설정사용자의 Google Calendar. 앱 서버에 저장하지 않음
Google 로그인 토큰로그인 유지사용자 기기(브라우저 저장소)에 암호화된 형태로 저장. 연결 해제 시 삭제·폐기
Google 계정 이메일, 기기 푸시 구독 정보, 사용자가 입력한 이름배우자 변경 알림 발송 대상 확인Cloudflare(앱 중계 서버) 저장소. 알림 끄기 시 삭제, 미사용 시 180일 후 자동 삭제
iCloud 공개 캘린더 링크 (사용자가 입력한 경우)해당 캘린더 일정 표시사용자 기기에만 저장. 중계 서버는 전달만 하고 저장하지 않음(최대 5분 캐시)
날씨 위치 (선택한 지역 또는 약 1km 단위로 반올림한 현재 위치)출퇴근 날씨 표시사용자 기기에만 저장. 예보 조회를 위해 Open-Meteo에 좌표 전달

2. Google 사용자 데이터

앱은 Google Calendar API 권한(https://www.googleapis.com/auth/calendar)을 위 목적에만 사용합니다. Google 사용자 데이터를 판매하거나 광고에 사용하지 않으며, 위 목적 외의 제3자에게 제공하지 않습니다. 앱의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 처리 위탁 및 외부 서비스

  • GitHub Pages — 앱 화면(정적 파일) 제공
  • Cloudflare Workers — 로그인 토큰 교환·갱신, iCloud 캘린더 중계, 푸시 알림 발송
  • Apple/Google 푸시 서비스 — 알림 전달
  • Open-Meteo — 날씨 예보 조회

4. 이용자의 권리

  • 앱 설정에서 언제든 Google 연결 해제, 알림 끄기, iCloud 캘린더 삭제를 할 수 있습니다.
  • Google 계정 › 서드파티 액세스에서 앱 권한을 철회할 수 있습니다.
  • 앱이 만든 캘린더와 일정은 Google Calendar에서 직접 삭제할 수 있습니다.
